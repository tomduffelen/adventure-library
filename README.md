# The Adventure Library

Choose-your-path puzzle adventures for young explorers — plus easy readers for children learning to read.

- **🌱 Easy readers** in three levels (Level 1 simplest → Level 3 longer pages, 6 puzzles): big, simple text, and a 🔊 "Hear it" button.
- **⚡ Quick stories** (about 7 min, 5 puzzles)
- **📘 Adventures** (about 15 min, 10 puzzles)
- **🏔️ Epic quests** (about 30 min, 16 puzzles, place saved automatically)

Puzzles include multi-step maths, fractions, minus numbers, secret codes, detective logic, compass maps and riddles. Every choice changes the path.

## Install as an app

It's a Progressive Web App: one `index.html`, plus `manifest.json`, `sw.js` (offline support) and icons. No build step.

1. Turn on GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / root → Save**.
2. Open `https://tomduffelen.github.io/adventure-library/` on a phone or tablet.
3. Tap **📲 Install as an app**.

Progress and saved places are stored in the browser on each device.
